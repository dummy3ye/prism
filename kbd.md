🔍 Search & Navigation (Telescope)
   * Space + f + f: Find Project Files (Smart project-root search)
   * Space + s + g: Live Grep (Search for text inside all files in the project)
   * Space + f + b: Find Open Buffers (Quickly switch between open files)
   * Space + f + h: Search Help (Neovim documentation)

  📂 File Tree (Neo-tree)
   * Ctrl + n: Toggle the file tree sidebar

  📑 Tabs & Buffers (Bufferline)
   * Shift + l: Next Tab
   * Shift + h: Previous Tab
   * Space + x: Close Current Tab

  💻 Coding & LSP (Language Support)
   * g + d: Go to Definition
   * K: Hover Documentation (Show function signatures)
   * Space + r + n: Rename Symbol (Project-wide)
   * Space + c + a: Code Actions (Fixes, imports, etc.)
   * g + r: List References
   * ] + d: Go to Next Error (Bug)
   * [ + d: Go to Previous Error
   * Space + e: Show full Error Detail (floating window)

  ✨ Structural Selection (Treesitter)
   * Space + s + s: Start structural selection
   * Space + s + i: Expand selection (word -> block -> function)
   * Space + s + d: Shrink selection

  🛠️ Other Useful File Operations
  While your cursor is on a file/folder in the tree:
   * a: Add File (type name) or Folder (type name/)
   * d: Delete (It will ask for confirmation).
   * r: Rename (Opens a prompt to change the name).
   * c: Copy (Copies the file/folder to the clipboard).
   * m: Move (Cut the file/folder).
   * p: Paste (Paste the file/folder you copied or moved).
   * y: Copy Name (Copies the filename to your system clipboard).
   * Y: Copy Path (Copies the absolute path to the file).
   * s: Open in Vertical Split
   * S: Open in Horizontal Split
   * t: Open in New Tab
   * P: Preview Mode (Toggle)
